# Log Schema

All simulator logs follow a standardized JSON schema for consistent processing.

## Standard Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `@timestamp` | string (ISO8601) | Yes | Event timestamp in UTC |
| `component` | string | Yes | Source component (traffic_management, iot_sensors, network) |
| `event_type` | string | Yes | Type of event |
| `severity` | string | Yes | Event severity (info, warning, high, critical) |
| `city_zone` | string | No | Smart city zone identifier |
| `src_ip` | string (IP) | No | Source IP address |
| `dst_ip` | string (IP) | No | Destination IP address |
| `src_port` | integer | No | Source port |
| `dst_port` | integer | No | Destination port |
| `actor_id` | string | Yes | Actor identifier (vehicle_id, sensor_id, etc.) |
| `message` | string | Yes | Human-readable event description |
| `metadata` | object | Yes | Component-specific metadata |

## Metadata Object

### Standard Metadata Fields

| Field | Type | Description |
|-------|------|-------------|
| `is_attack` | boolean | Whether event is part of attack (for labeled datasets) |
| `attack_type` | string | Type of attack (if applicable) |
| `attack_start_time` | string (ISO8601) | Attack start timestamp |

## Component-Specific Schemas

### Traffic Management Events

```json
{
  "@timestamp": "2026-02-08T10:00:00Z",
  "component": "traffic_management",
  "event_type": "vehicle_movement",
  "severity": "info",
  "city_zone": "zone_1",
  "src_ip": "10.1.2.100",
  "dst_ip": "10.1.2.200",
  "src_port": 45123,
  "dst_port": 443,
  "actor_id": "vehicle_0042",
  "message": "vehicle_movement in zone_1 by vehicle_0042",
  "metadata": {
    "is_attack": false,
    "speed": 55,
    "vehicle_type": "car"
  }
}
```
